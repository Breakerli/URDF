# 维护URDF

## 1. 添加自研第一版机器人HT-0_58
命名说明：HT-0出自结构命名方式，尾缀'_58'指的是机体质量为58kg。

### 坐标系说明
- 基座坐标系：绑定在机器人胸前的IMU上


| x正方向 | y正方向 | z正方向 |
| :-----: | :----: | :----: |
| 身体前进方向 | 指向身体左侧 | 垂直地面向上 |

- 关节坐标系：机器人各个关节坐标系

在零位状态下的方向与基座坐标系方向相同，即后摆是正、左摆是正、从上往下看逆时针是正。
